# Changelog

## 1.0.0

First release.

- Transmog gun parts, magazines, iron sights and gear. Only the model changes. The item and its stats stay the real ones.
- Hide gear from your character. It still works, and other players with the mod see it hidden too.
- A violet tag marks transmogged items. Hover it to see the look.
- Hold Alt in the inventory to swap icons between the real item and the look. Inventory icons in F12 sets which one shows by default.
- Looks follow in F12. Slot (default): a plain item in the same slot takes the look. Item: a look stays on its one item.
- WTT Pack n Strap belts can be transmogged when that mod is installed.
- Fika: players running the mod see each other's looks. Loaded only when Fika is installed.
- Examined items only in F12, off by default: only offer looks of items you've examined.
- Two menu styles in F12: Integrated and Spotlight.
