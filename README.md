# transMOGGED

Transmog (short for transmogrification) is a video game feature that lets you change the visual appearance of your equipment without altering its combat stats, attributes, or set bonuses.

Mog EVERYONE with your new transmogged gear. Or your pal, because it works with Fika.

Right click an item in your stash, pick **Transmog**, pick a look, press **Apply**.

Works on gun parts, magazines, iron sights and gear. Gear can be hidden too. Adds nothing to the server, so it won't clash with item mods.

## Install
SPT 4.1.x. Client only, no server part.

1. Download the zip.
2. Extract it into your SPT folder.

To update, extract over the old one. To remove, delete `BepInEx\plugins\transMOGGED`. Your looks are saved in that folder, so they go with it.

## Use
- **Original** puts an item back.
- **Hide** takes gear off your character. It still works.
- Hover the violet tag to see the look.
- Hold **Alt** in the inventory to swap the icons.

Scopes, lights and the gun itself can't be changed. Suppressors only look like suppressors. Magazines only look like magazines of the same size and caliber.

## Fika
Everyone with the mod sees each other's looks. The host needs it too, headless included. Players without it see the real items.

## Settings
Press **F12** in game.

| Setting | What it does |
| --- | --- |
| Enabled | Turns all looks on or off. Your picks are kept. |
| Show other players looks | Shows looks from other players in Fika. |
| Mark transmogged items | Shows the violet tag. |
| Menu style | Integrated matches the game. Spotlight is the bigger violet style. |
| Inventory icons | Show the real item or the look. Alt shows the other one. |
| Looks follow | Slot means a plain item in that slot takes the look. Item means a look stays on its one item. |
| Examined items only | Only offers looks of items you've examined. |

Each type of gun part and gear can be turned off if you don't want it. Barrels are off by default, as they move the muzzle.
